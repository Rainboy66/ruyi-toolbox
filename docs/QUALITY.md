## 本仓库的公开复现

`tests/` 只生成合成文字、图形与图像：图片透明度/编码、源 JPEG 复用、PDF 页面整理/撤销、宫格、小册子、规则预设及批量异常隔离等。它用于验证公开目录可独立导入并完成这些行为，不代替所有复杂文档和办公软件兼容验证。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

公开整理期间的检查记录见 `PUBLICATION_CHECK.json`。GitHub Actions 使用 Windows + Python 3.12 执行同一公开测试；首次远程运行前不声称 CI 已通过。

不承诺所有文件 1:1、OCR 自动恢复、所有机器完全流畅或任意 PDF 的注释/表单无损。问题反馈请使用脱敏、自建样例，不上传个人证件或未经许可的文件。

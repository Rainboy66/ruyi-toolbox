# 使用说明

- Office 转 PDF：添加 DOC/DOCX、XLS/XLSX、PPT/PPTX，选输出目录和本机排版引擎后转换；缺少字体、外部资源或本机办公引擎会影响结果。禁止以输出替换原件。
- PDF 转 Office：选择 Word、Excel 或 PPT。文字页尽力重建可编辑内容；扫描页保持图像，当前不含自动 OCR。PPT 的外观保真输出与可编辑重建性质不同。
- 图片压缩：选择格式、画质、最大边或目标体积。质量百分比不是文件体积比例；同格式同尺寸时，若结果未变小，程序避免保留膨胀结果。缩小像素和无损不是同一件事。
- 证件照换底：首次准备模型后本地推理。预设 HEX 是产品颜色选项，不能替代办理机构对尺寸、背景和印刷的具体要求。
- PDF 合并拼凑：导入多个 PDF，在源页网格选择/拖拽；Del 删除、Ctrl+D 复制、R 旋转、Ctrl+Z/Y 撤销重做。宫格预览可交换页位；保存方案继续使用源文件引用，移动或改写源 PDF 可能导致校验失败。
- 拼版与规则：2/4/6/9 宫格可选 Z 字/列优先、间距和边框；骑马钉可选装订边和双面翻转；支持长页及页码/水印/印章/PDF 背景。规则顺序影响结果，页码放在拼版前后含义不同。

适应保持内容完整，填充会裁去部分边缘，拉伸会改变比例。交互表单和某些注释/跳转无法安全拼版时会报告原因；损坏或不支持的单个文件不应中断批量其他文件。

设置和运行日志保存在本机用户配置区；快捷方式由用户显式操作创建。自动获取模型时需要联网，文件转换和照片处理不上传源内容。
